1️⃣ HTML Table

Table ka basic structure:

<table>
    <tr>
        <th>Name</th>
        <th>Course</th>
        <th>Year</th>
    </tr>

    <tr>
        <td>Shivam</td>
        <td>BCA AI & ML</td>
        <td>2nd Year</td>
    </tr>
</table>
Samjho:

<table> → poori table

<tr> → Table Row

<th> → Table Heading

<td> → Table Data

Structure:

        Name       Course          Year
         ↓           ↓              ↓
       ┌───────┬─────────────┬─────────┐
       │ Name  │ Course      │ Year    │
       ├───────┼─────────────┼─────────┤
       │ Shivam│ BCA AI & ML │ 2nd     │
       └───────┴─────────────┴─────────┘
2️⃣ border kya hota hai?

Abhi CSS nahi seekha hai, isliye basic practice ke liye:

<table border="1">

Isse table ki boundaries visible ho jayengi.

Note: Professional websites mein hum baad mein CSS se border lagayenge.

4️⃣ HTML Forms 📝

Form ka use user se information lene ke liye hota hai.

Examples:

Login
Registration
Contact Us
Feedback
Search
Student information

Basic form:

<form>

    <label>Name:</label>
    <input type="text">

    <br><br>

    <label>Email:</label>
    <input type="email">

    <br><br>

    <button>Submit</button>

</form>
5️⃣ Input Types

HTML mein different types ke inputs hote hain.

Text
<input type="text">

Name ke liye.

Email
<input type="email">

Email ke liye.

Password
<input type="password">

Password ke liye.

Number
<input type="number">

Number ke liye.

Date
<input type="date">

Date select karne ke liye.

File
<input type="file">

File upload ke liye.

Radio
<input type="radio" name="gender"> Male
<input type="radio" name="gender"> Female

Radio buttons mein name same rakhne se ek group banta hai.

Checkbox
<input type="checkbox"> HTML
<input type="checkbox"> CSS
<input type="checkbox"> JavaScript

Checkbox mein multiple options select kiye ja sakte hain.

6️⃣ Label ka use

Better form:

<label for="name">Name:</label>
<input type="text" id="name">

Yahan:

for="name"
      ↓
id="name"

Dono connected hain.
